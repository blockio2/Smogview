**Overview**
Smogview is a narrative puzzle game being built by a team of RIT students for the Games for Change competition.
Quarantined in a run down city cluster, traverse the world using a lens-switching mechanic to make puzzles approachable.

**Download Instructions:**
Unzip folder and run executable

**Controls:**
WASD to move
0, 1, 2, 3 to switch between lenses
E to interact
